# 2026-10-27 工作日志

## AI 记账工具（从零搭建）

按用户提供的《账本开发.docx》需求 + 口袋记账 8 张截图，设计并实现了「为 AI 记账而生」的本地记账工具。

### 核心设计（灵魂）
用户一个月记一次总账，现金账户是「中转枢纽」：
1. 平账：各账户对齐实际余额，差额净流入现金
2. 记账：所有明细支出/收入全从现金走
3. 清零：按现金余额记一条平账记录，现金归零（差额=无法逐笔统计的一般性支出）

### 技术选型（用户已拍板）
- Node.js 22 + Express + better-sqlite3（SQLite 单文件 `data/zhangben.db`）
- 原生 HTML/CSS/JS 前端（无构建），对齐口袋记账风格（浅米白背景、蓝色主色、多彩账户卡片、数字键盘）
- 鉴权：网页密码（默认 admin123）+ API Bearer token（登录即返回）
- 周期账：应用内定时器（每 60s 检查）+ 简写 cron `MONTHLY:1`
- 邮件备份：SMTP 配置项，未配则跳过

### 金额单位约定
**全部用「分」整数存储**，展示时 /100。这是给 AI 的关键约定（SKILL.md 里写明）。

### 目录结构
- `server.js` 入口 · `src/db.js` 建表+种子 · `src/domain/` 核心域逻辑（accounts/entries/periodic/report）
- `src/routes/` REST 路由 · `src/auth.js` 鉴权 · `src/backup.js` 邮件备份
- `public/` 前端 · `test/` node:test（20/20 通过）· `SKILL.md` 供 AI 调用

### 关键坑（已踩已修）
- better-sqlite3 里 SQL 字符串比较用 `<> ''`，不能写 `!= ""`（会被当成列名报 `no such column: ""`）
- ESM 下无 `__filename`，用 `import.meta.url` 派生 `__dirname`
- `node --test` 目录参数需通配符 `"test/**/*.test.js"`
- 登录返回 token 需直接带在响应里，避免前端二次请求 `/api-token` 的死锁（该接口要 Bearer token）
